# 📝 Anas Notes – Flutter Notes Taking App

A simple and user-friendly Notes Taking App built with **Flutter, Dart, and SQLite**. The app allows users to create, view, edit, and delete notes, with customizable colors to organize their thoughts.

## ✨ Features

* ➕ Create new notes
* 📖 View saved notes
* ✏️ Edit existing notes
* 🗑️ Delete notes
* 🎨 Choose different colors for notes
* 💾 Store notes locally using SQLite
* 📱 Responsive interface for Android devices

## 🛠️ Technologies Used

* **Flutter** – Cross-platform UI framework
* **Dart** – Programming language
* **SQLite** – Local database
* **Android Studio** – Development environment

## 🚀 Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or another Flutter-compatible IDE
* An Android emulator or physical device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/anasamin100100-eng/Anas-notes.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Anas-notes
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## 📦 Build APK

To generate a release APK, run:

```bash
flutter build apk --release
```

The APK will be available at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
